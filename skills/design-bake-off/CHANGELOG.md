# Changelog

## 1.2.0 — 2026-10-06

- Manniche UI first: the design agents prefer the components in this repo (recreated in plain JS/CSS) over other libraries' versions of an effect.
- Dangerous actions: the six rules for anything that deletes or cannot easily be undone, with the matching components (`hold-to-confirm`, `confirm-dialog`, `danger-zone`, `timed-undo`, `scheduled-deletion`), in the rules and in the direction prompt.
- Refero Styles as the frame for each direction: the brief has an optional "Style frames" section, and the direction prompt reads the assigned `DESIGN.md`.
- New "Sources outside the folder" table: React Bits Background Studio and Texture Lab, Aceternity UI (inspiration only), transitions.dev and make-interfaces-feel-better, each with what its licence allows.
- The README links make-interfaces-feel-better at its upstream repository.

## 1.1.0 — 2026-10-03

- The port step installs effects from the Manniche UI shadcn registry when the app is React with shadcn, instead of rewriting them.

## 1.0.0 — 2026-10-03

- First public version: brief template, prompts for three design agents and a port agent, and a reference page of UI effects in plain JS/CSS.
